# Gloomhaven: Jaws of the Lion Rules Interpreter

Version `0.1.0` is a limited onboarding interpreter built from the uploaded 32-page Learn to Play guide. It provides original play-flow and timing aids without bundling guide text, card text, scenario text, or artwork.

## Coverage

Coverage is intentionally limited to the guide’s first five scenarios and the mechanics it introduces: round structure, card selection, initiative, exhaustion, short rests, and campaign bookkeeping. The guide itself directs players to final rules and a Rules Glossary. Exact monster abilities, scenario objectives, item/card wording, and later-campaign exceptions are `not_yet_covered` locally.
