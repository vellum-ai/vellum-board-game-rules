# War of the Ring: Second Edition Rules Interpreter

Version `0.1.0` is an original-interpretation and timing aid for the uploaded 48-page Second Edition v24.1 rulebook. It does not bundle rulebook text, event/card text, artwork, or long quotations.

## Coverage

The corpus covers the six-phase turn, action-die/Hunt timing, selected Second Edition deltas, Ring-based and military victory checks, and settlement point values. It is not a substitute for the complete reference, especially for combat, politics, Hunt tiles, cards, characters, multiplayer rules, and exceptions.
