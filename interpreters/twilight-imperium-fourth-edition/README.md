# Twilight Imperium: Fourth Edition Rules Interpreter

Version `0.1.0` is a limited original-interpretation aid for the uploaded 24-page 2020 Learn to Play guide. It does not bundle guide text, card text, faction text, artwork, or long quotations.

## Coverage

The package covers the four-phase round, strategy-card initiative, passing, tactical and strategic action order, status-phase objective timing, and the 10-point end condition. It is deliberately not a complete Rules Reference. Faction abilities, technologies, combat, agendas, component exceptions, and expansion rules require an authorized current source or `not_yet_covered`.
